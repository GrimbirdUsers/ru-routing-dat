## Воспроизводимость

`scripts/build_metadata.py` формирует счётчики из бинарников. `scripts/validate_abc.py --qr` сверяет сборку с исходниками, проверяет весь согласованный доменный набор, точные хосты, удаления, Twitch, ссылки на категории, deeplink и DEFAULT QR.

Содержимое баз проверяется отдельно от политики маршрутизации. Для применения нового состава доменов клиент должен загрузить свежий `geosite.dat`; для исправления ссылки `mailru` в ранее импортированном DEFAULT нужен импорт обновлённого профиля.

Проверка относительно исходного коммита `302cf69387744ebf47b71dc856922dd7438e0076` выполнена командой:

```sh
python3 scripts/validate_abc.py --qr --baseline 302cf69387744ebf47b71dc856922dd7438e0076
```

Результат: 105 согласованных правил дают новое покрытие; пять ошибочных правил удалены. После оптимизации вложенных правил число записей `category-ru-whitelist` изменилось с 531 до 629; число категорий geosite составляет 63.

Оба DEFAULT QR декодируются обратно в актуальные URI. GeoIP, все файлы профилей WHITELIST/JSONSUB и остальные параметры DEFAULT совпадают с исходным коммитом; подробные счётчики и SHA256 находятся в [статистике сборки](../CATEGORY_STATS.md).
